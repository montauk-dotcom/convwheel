# ConvWheel

Фоновое приложение для Windows и macOS: **Shift + клик по файлу** в Проводнике/Finder или
на рабочем столе — и вокруг курсора плавно раскрывается колесо с форматами, в которые этот
файл можно сконвертировать. Выбрали сектор — в центре идёт прогресс, готовый файл
появляется рядом с исходным. Клик по центру — показать результат в папке.

## Что во что конвертируется

| Исходный файл | Варианты | Чем |
|---|---|---|
| DOCX, DOC, ODT, RTF | PDF, TXT, DOCX, ODT, RTF, HTML, DOC | MS Word (Windows) или LibreOffice; DOCX→TXT — напрямую |
| TXT, MD | PDF, DOCX, HTML, ODT, TXT (UTF-8 / без разметки) | python-docx, LibreOffice |
| PDF | DOCX, TXT, PNG, JPG (каждая страница) | pdf2docx, PyMuPDF |
| XLSX, XLS, ODS | PDF, CSV (каждый лист), XLSX, ODS | MS Excel или LibreOffice; запасной путь — openpyxl |
| CSV | XLSX, PDF, ODS | openpyxl (сам определяет `,` / `;`), LibreOffice |
| PPTX, PPT, ODP | PDF, PPTX, ODP | MS PowerPoint или LibreOffice |
| PNG, JPG, WEBP, GIF, BMP, TIFF, HEIC, ICO | PNG, JPG, WEBP, PDF, ICO, GIF, BMP, TIFF | Pillow |
| MP4, MOV, MKV, AVI, WEBM… | MP4, MP3, GIF, WEBM, MOV, WAV | ffmpeg (идёт в комплекте) |
| MP3, WAV, FLAC, OGG, M4A… | MP3, WAV, FLAC, OGG, M4A | ffmpeg |
| **Папка** | ZIP, 7Z, TAR.GZ · картинки → один PDF · документы → PDF · фото → JPG · сжать фото для отправки · список файлов | zipfile, py7zr, tarfile, Pillow, LibreOffice |
| **Архив** ZIP, 7Z, TAR.GZ | Распаковать · перепаковать в другой формат | zipfile, py7zr, tarfile |

Несколько выделенных картинок → дополнительно «PDF · Один файл». Для папки показываются
только действия, подходящие её содержимому (нет картинок — нет «картинки → PDF»).
Распаковка защищена от вредных архивов с путями вида `../../`; имена из Windows-архивов
(CP866) не превращаются в кракозябры.

## Вид колеса
Восемь видов, по умолчанию — **Цитрус** (серая однотонная долька в разрезе):

| Вид | Как выглядит |
|---|---|
| **Цитрус** | серая долька: корка с порами, белая мякоть, скруглённые дольки |
| **Апельсин**, **Лайм** | та же долька, в цвете |
| **Неон** | тёмное колесо с цветными подписями и свечением (вид из первой версии) |
| **Синтвейв** | фиолетовый неон с розовым и бирюзовым |
| **Стекло** | светлые матовые плитки, выбор — синим, как в macOS |
| **Графит** | тёмные плитки, выбор — белым |
| **Винил** | пластинка с дорожками и бликами, в центре — оранжевая «наклейка» |

Выбрать: значок → **Вид колеса** (список, выбранный вид сразу показывается вживую) или
**Вид и настройки…** — окно с превью всех видов. Новый вид добавляется одной записью в
`convwheel/themes.py`.

## Значок и окно настроек
- **macOS** — значок-долька в строке меню справа вверху, одноцветный, сам подстраивается под
  светлую и тёмную строку меню (как у Forti, AmneziaVPN). Клик — меню.
- **Windows** — значок в трее; цвет подбирается под тему панели задач. Клик — окно «Вид и
  настройки», правый клик — меню.
- Если значка не видно (на MacBook с «чёлкой» лишние значки прячутся за ней), просто откройте
  ConvWheel ещё раз — появится окно настроек. Значки в строке меню можно переставлять,
  перетаскивая их с зажатой `Cmd`.

## Надёжность
- Конвертация идёт в отдельном процессе: если библиотека упадёт на «плохом» файле, колесо
  покажет ошибку, а ConvWheel продолжит работать.
- Если ConvWheel всё же упадёт, сторож сразу запустит его снова (Windows — процесс-сторож,
  macOS — watchdog). Принудительное завершение из Диспетчера задач / Мониторинга системы
  сторож уважает.
- Перехват мыши сам восстанавливается: macOS иногда отключает его — включаем обратно сразу;
  Windows может молча снять его — переустанавливаем каждые 30 секунд.
- Журналы: `convwheel.log` и `crash.log` в папке настроек (см. ниже) — пришлите их, если что-то не так.

### Чтобы конвертация была правильной
- Прозрачный PNG → JPG/PDF получает белый фон, а не чёрный; фото с телефона не поворачиваются (EXIF).
- Текстовые файлы в CP1251/UTF-16 читаются корректно, результат всегда UTF-8 — без кракозябр.
- PDF-скан без текстового слоя не превращается молча в пустой TXT/DOCX — будет понятное сообщение.
- Существующие файлы никогда не перезаписываются: `Отчёт.pdf` → `Отчёт (1).pdf`.
- Результат сначала собирается во временной папке, проверяется (существует, не пустой) и только потом переносится.
- LibreOffice запускается с отдельным профилем, поэтому не мешает открытому у вас LibreOffice.
- Видео в MP4 — H.264 + AAC + `faststart`: открывается везде, включая телефоны и Telegram.

## Установка

Нужен Python 3.10+.

```bash
pip install -r requirements.txt
python main.py
```

Для офисных форматов нужен **LibreOffice** (бесплатно, libreoffice.org). На Windows вместо
него можно использовать установленный Microsoft Office — он даёт самое точное PDF.
Проверить, всё ли найдено: значок в трее → «Проверить компоненты».

### Windows
Ничего дополнительно разрешать не нужно. Автозапуск — в меню значка в трее.

### macOS
При первом запуске откроются окно «Вид и настройки» и окно «Почти готово» с тремя
разрешениями (Универсальный доступ, Мониторинг ввода, доступ к Finder). Кнопки сразу
открывают нужный раздел настроек, статус обновляется сам; если нужен перезапуск —
ConvWheel перезапустится сам. Открыть снова: значок → «Разрешения macOS…».

## Готовые сборки без Терминала (GitHub Actions)

В проекте есть `.github/workflows/build.yml`: при каждой загрузке изменений GitHub сам собирает
- **macOS**: `ConvWheel-<версия>-arm64.dmg` (M1–M4) и `…-x86_64.dmg` (Intel);
- **Windows**: установщик `ConvWheel-Setup-<версия>.exe` (без прав администратора, с автозапуском)
  и `ConvWheel-<версия>-windows-portable.zip`.

Каждая сборка перед выкладкой запускает готовое приложение в режиме самопроверки.

Windows без платной подписи кода покажет «Windows защитила ваш компьютер» →
«Подробнее» → «Выполнить в любом случае». Это один раз.

1. Создайте репозиторий на github.com (можно приватный).
2. «uploading an existing file» → перетащите **всё содержимое** папки `convwheel`.
   В Finder нажмите `Cmd + Shift + .`, чтобы увидеть скрытую папку `.github`, — её тоже нужно перетащить.
3. Вкладка **Actions** → «Сборка» → через ~15 минут внизу появятся
   `ConvWheel-macOS-arm64`, `ConvWheel-macOS-x86_64`, `ConvWheel-Windows-Setup`,
   `ConvWheel-Windows-Portable` — скачайте нужное.
4. Чтобы DMG публиковался на странице Releases, создайте релиз с тегом вида `v1.0.0`.

Без сертификата Apple Developer ($99/год) macOS при первом открытии скажет, что не может
проверить разработчика: «Системные настройки → Конфиденциальность и безопасность →
Всё равно открыть». Это один раз. С сертификатом добавьте секреты репозитория
`MACOS_CERT_P12` (base64 от .p12), `MACOS_CERT_PASSWORD`, `MACOS_SIGN_IDENTITY` и для
нотаризации `MACOS_NOTARY_APPLE_ID`, `MACOS_NOTARY_PASSWORD`, `MACOS_NOTARY_TEAM_ID` —
тогда предупреждения не будет вовсе.

## Сборка вручную

- Windows: `build_windows.bat` → `dist\ConvWheel-Setup-<версия>.exe` и portable-архив
- macOS: `./build_macos.sh` → `dist/ConvWheel-<версия>-<arch>.dmg`

Собирать нужно на той системе, для которой сборка.

## Управление колесом
- Навести и кликнуть по сектору — конвертировать; цифры `1–8` — то же с клавиатуры.
- `Esc`, правый клик, клик по центру или мимо колеса — закрыть.
- После готовности: клик по центру / `Enter` — показать файл в папке. Колесо закроется само через пару секунд.

## Настройки
Меню значка и окно «Вид и настройки»: вид колеса, вкл/выкл, кнопка вызова (Shift + левая /
колёсико / правая), офисный движок (Windows), автозапуск. Остальное — в `config.json`:
- Windows: `%APPDATA%\ConvWheel\config.json`
- macOS: `~/Library/Application Support/ConvWheel/config.json`

`output_dir` — общая папка для результатов (по умолчанию рядом с исходником),
`pdf_image_dpi`, `jpeg_quality`, `selection_delay_ms`. Журналы — `convwheel.log` и `crash.log` там же.

### Про Shift + левую кнопку
В Проводнике и Finder Shift+клик ещё и выделяет диапазон файлов. На Windows колесо всегда
берёт именно тот файл, по которому кликнули (через UI Automation). На macOS берётся
выделение Finder — если там окажется несколько файлов, колесо предложит пакетную конвертацию.
Если мешает — переключите кнопку на **Shift + колёсико**: выделение не меняется, а на Windows
так можно конвертировать сразу все выделенные файлы (кликнув по одному из них).

## Структура
```
main.py                     запуск и служебные режимы (--agent, --worker, --watchdog)
convwheel/supervisor.py     сторож Windows: один экземпляр, перезапуск после падения
convwheel/watchdog.py       сторож macOS
convwheel/app.py            значок, меню, связь перехвата и колеса
convwheel/jobs.py           владелец колёс и конвертаций (отдельные процессы)
convwheel/worker.py         процесс-исполнитель одной конвертации
convwheel/wheel.py          радиальное меню, анимации, 4 стиля отрисовки
convwheel/themes.py         8 видов колеса
convwheel/settings_window.py окно «Вид и настройки» с превью
convwheel/icons.py          значок строки меню / трея
convwheel/ipc.py            «открыть ещё раз» → окно настроек
convwheel/trigger/          перехват мыши: windows.py (WH_MOUSE_LL), macos.py (Quartz event tap)
convwheel/formats.py        какие варианты показывать для какого файла
convwheel/engine.py         выполнение: временная папка → проверка → перенос
convwheel/converters/       office, pdf, image, media, text, sheet, archive, folder
convwheel/mac_permissions.py окно разрешений macOS при первом запуске
packaging/                  установщик Windows (Inno Setup), entitlements macOS
tools/make_icon.py          иконка приложения
tests/                      конвертация, папки, жизненный цикл колеса, надёжность, превью видов
```

Отладка без клика: `python main.py --file путь/к/файлу.docx`.
Пример колеса без файла: `python main.py --demo`.
Тесты: `python tests/make_fixtures.py`, затем `test_convert.py`, `test_folders.py`,
`test_lifecycle.py`, `test_robustness.py`.
